## Обзор проекта

Этот проект реализует классический цикл уличного светофора на плате разработки ESP32-WROOM (4 MB Flash). В отличие от учебных примеров на Arduino, здесь используется ESP-IDF — официальный фреймворк Espressif для коммерческой разработки.

Что демонстрирует проект:
- Практическое применение C++ и ООП: логика светофора инкапсулирована в классе TrafficLight, что делает код переиспользуемым и чистым.
- Работа с GPIO на низком уровне через драйвер driver/gpio.h (конфигурация через gpio_config_t, а не digitalWrite).
- Использование FreeRTOS для неблокирующих задержек (vTaskDelay).
- Понимание структуры проекта ESP-IDF: разделение на main и пользовательские файлы, работа с CMakeLists.txt.

Цель: Закрепить базовые навыки embedded-разработки и создать точку отсчёта для более сложных проектов (Wi-Fi, датчики, RTOS-задачи).

## Функции

- Полный цикл светофора: Красный (3 сек) → Жёлтый (1 сек) → Зелёный (3 сек) → Жёлтый (1 сек) → Красный.
- Объектно-ориентированная архитектура: класс TrafficLight инкапсулирует пины и логику переключения.
- Безопасная работа с GPIO: настройка пинов через gpio_config_t с явным указанием режима OUTPUT и отключением подтяжек (для выходов это правильно).
- Энергонезависимая задержка: используется vTaskDelay, а не delay() (не блокирует планировщик FreeRTOS, если в будущем появятся другие задачи).

## Аппаратные компоненты

| Компонент | Количество | Назначение | Примечание |
| :--- | :--- | :--- | :--- |
| ESP32-WROOM DevKit | 1 | Микроконтроллер | Ревизия v3.1, 4 MB Flash |
| Светодиод (красный) | 1 | Сигнал «Стоп» | 5 мм, 2.0–2.2 В |
| Светодиод (жёлтый) | 1 | Сигнал «Внимание» | 5 мм, 2.0–2.2 В |
| Светодиод (зелёный) | 1 | Сигнал «Иди» | 5 мм, 2.0–2.2 В |
| Резистор 220 Ом | 3 | Ограничение тока | Обязательно! Защита пинов ESP32 (макс. 12 мА) |
| Соединительные провода | — | Монтаж | Мама-папа |
| Макетная плата | 1 | Сборка схемы | — |

Важно: Каждый светодиод имеет свой токоограничивающий резистор. Нельзя использовать один резистор на несколько светодиодов параллельно — из-за разброса параметров они будут гореть неравномерно, а при перегорании одного остальные могут выйти из строя.

## Схема подключения (Wiring Diagram)

Текстовое описание (при необходимости замени на картинку схемы).

| Сигнал светофора | Пин ESP32 | GPIO | Цвет провода (пример) |
| :--- | :--- | :--- | :--- |
| Красный | GPIO 13 | GPIO_NUM_13 | Красный |
| Жёлтый | GPIO 12 | GPIO_NUM_12 | Жёлтый |
| Зелёный | GPIO 14 | GPIO_NUM_14 | Зелёный |
| Земля (GND) | GND | — | Чёрный |

Схема цепи для каждого светодиода:
ESP32 GPIO → Резистор 220 Ом → Анод светодиода → Катод светодиода → GND ESP32

(Картинку схемы можно нарисовать в Fritzing или любом редакторе и положить в папку images/wiring.png)

## Программные требования

- ESP-IDF v6.1 (или совместимая v5.x)
- VS Code + официальное расширение ESP-IDF Extension
- Компилятор: xtensa-esp32-elf-gcc
- CMake (устанавливается вместе с ESP-IDF)
- Драйвер USB-UART для платы (CP210x или CH340)

## Установка и сборка

1. Клонируй репозиторий:
    git clone https://github.com/твой-ник/esp32-traffic-light.git
    cd esp32-traffic-light

2. Активируй окружение ESP-IDF в терминале VS Code (или через иконку ESP-IDF в статус-баре).

3. Настрой размер Flash под свою плату (если необходимо):
    idf.py menuconfig
   → Serial flasher config → Flash size → 4 MB.

4. Собери проект:
    idf.py build

5. Прошей и запусти монитор:
    idf.py -p COM7 flash monitor
   (Замени COM7 на свой порт. Выход из монитора — Ctrl+])

## Архитектура кода

    esp32-traffic-light/
    ├── CMakeLists.txt          # Корневой файл сборки ESP-IDF
    ├── main/
    │   ├── CMakeLists.txt      # Регистрация исходников компонента main
    │   ├── main.cpp            # Точка входа (extern "C" app_main)
    │   ├── TrafficLight.hpp    # Объявление класса TrafficLight
    │   └── TrafficLight.cpp    # Реализация методов класса
    ├── images/
    │   └── demo.gif            # (сюда положишь гифку)
    └── README.md

Ключевое решение: Логика светофора вынесена в отдельный класс TrafficLight. Конструктор только сохраняет номера пинов, а метод init() выполняет реальную настройку GPIO. Это разделение позволяет легко менять пины без правки логики и переиспользовать класс в других проектах.

## Использование

После прошивки светофор запускается автоматически. Цикл бесконечный. Чтобы изменить время горения, отредактируй константы в TrafficLight.cpp (или в main.cpp, в зависимости от реализации) и пересобери проект.
